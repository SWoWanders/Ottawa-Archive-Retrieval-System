Library and Archives Canada — send from the LAC site

LAC blocks scripts that run anywhere but on its own pages, so this works in two steps: a bookmarklet runs on a LAC results page, collects photos whose copyright is marked expired, then sends them back here, where they appear in the grid with everything else.

  1. Put lac-collector.js in the same folder as this page on your site.
  2. Copy the bookmarklet below and save it as a bookmark (name it LAC).
  3. On a LAC results page (Images filter), type LAC in the address bar and tap the bookmark.
  4. When it finishes, tap Send photos to the app. This page opens and fills the grid.
